# Помощник для онлайн-школы

Комплексное приложение для управления онлайн-школой.

## Функции

- Управление учителями и учениками
- Планирование уроков
- Отслеживание зарплаты учителей
- Управление абонементами и платежами
- Отслеживание должников
- Аналитика по периодам
- Повторяющиеся уроки
- Управление задачами

## Развертывание на Vercel

1. Зайдите на https://vercel.com
2. Нажмите "New Project"
3. Импортируйте этот репозиторий
4. Нажмите Deploy

Приложение будет доступно по адресу вроде: https://school-assistant.vercel.app

## Использование

Все данные хранятся локально в localStorage браузера. Используйте Export/Import JSON для резервного копирования.
